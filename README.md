# CyberSentinel

CyberSentinel is an AI-powered Personal Cybersecurity Command Center designed to provide users with a unified platform for analyzing and assessing common cybersecurity threats.

The platform integrates multiple cybersecurity modules into a single dashboard, including phishing detection, network reconnaissance, traffic analysis, file security analysis, and password security assessment. It also includes a centralized risk engine that combines security analysis results to generate an overall risk score and risk level.

The phishing detection system uses machine learning and URL-based feature analysis to identify potentially malicious or suspicious URLs. The platform combines automated analysis with a centralized dashboard to help users understand security risks and take appropriate action.

## Key Features

- Machine learning-based phishing URL detection
- URL feature extraction and analysis
- Network reconnaissance and security analysis
- Network traffic analysis
- File security analysis
- Password security assessment
- Unified cybersecurity risk scoring
- Centralized security dashboard
- Modular backend architecture
- React-based frontend interface

## Project Objective

The primary goal of CyberSentinel is to bring multiple cybersecurity assessment capabilities together into one accessible platform. Instead of relying on separate tools for different security checks, users can access multiple security analysis modules through a unified interface and receive an overall assessment of their security posture.

## Architecture

CyberSentinel follows a modular architecture consisting of:

- Frontend: Provides the interactive cybersecurity dashboard.
- Backend: Handles API requests and coordinates security analysis modules.
- Machine Learning Layer: Performs phishing detection and URL feature analysis.
- Security Modules: Perform file, network, traffic, password, and phishing analysis.
- Risk Engine: Aggregates analysis results and generates a unified security risk score.
